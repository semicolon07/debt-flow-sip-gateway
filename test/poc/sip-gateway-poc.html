Debt Flow SIP Gateway POC

ทดสอบ WSS protocol v1, WebRTC audio, SIP registration และ call control โดยไม่ผ่าน Angular UI

ใช้กับ development environment เท่านั้น ข้อมูล capability และ bearer token อยู่ใน memory ของ tab นี้ และจะไม่ถูกเขียนลง browser storage หรือ event log

1. Gateway session

WSS: disconnected WebRTC: idle SIP: unknown Call: idle
Standalone POC: Browser → Gateway โดยไม่ใช้ Web API
Development เท่านั้น: browser จะสร้าง encrypted capability จาก key ด้านล่าง โดย SIP password และ key อยู่เฉพาะใน memory ของ tab และไม่ถูก log
Advanced: transport, realm และ capability key

2. Audio / WebRTC

Silent audio ใช้ทดสอบ REGISTER, call signaling และ media negotiation โดยไม่จับเสียงจากเครื่อง ส่วนเสียง ringtone/ringback สร้างใน browser และออกทาง default speaker

Selected ICE route: —

3. SIP registration

โหมด API ใช้ SIP bootstrap ใน capability; โหมด Standalone ใช้ค่าที่กรอกในส่วน 1 เพื่อสร้าง capability ใน browser

4. Call control

Inbound รองรับ: PBX ต้อง route extension มาที่ Contact ของ Gateway; เมื่อ INVITE เข้า POC จะแสดงหมายเลข, เล่น ringtone และเปิดปุ่ม Answer/Reject อัตโนมัติ

5. Sanitized event log
